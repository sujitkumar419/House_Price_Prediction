# 🏡 House Price Prediction

This project predicts house prices using the Ames Housing dataset and a Random Forest model trained on 245 features.  
It includes an interactive Streamlit dashboard where users can input property details (LotArea, OverallQual, GrLivArea, GarageCars, YearBuilt, etc.) and get instant price predictions.

## Features
- Full ML model trained on 245 features
- Streamlit dashboard for interactive predictions
- User-friendly inputs for key property attributes
- Easily extendable to include more features

## Tech Stack
- Python
- scikit-learn
- pandas
- Streamlit

## How to Run
```bash
streamlit run app.py
